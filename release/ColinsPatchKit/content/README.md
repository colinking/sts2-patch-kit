# Colin's Patch Kit

A mod for Slay the Spire 2 with **15 quality-of-life improvements**. These patches are intended to feel like missing vanilla features.

All patches do not impact gameplay, nor competitive integrity. This mod supports the latest stable version (`v0.107.1`) and the latest beta version (`v0.108.0`), and is safe for use in multiplayer.

Please submit feedback / feature requests [via GitHub](https://github.com/colinking/sts2-patch-kit/issues).

## Installation

Click `Subscribe` and restart your game.

## Patches

All patches are **enabled by default** and can be toggled individually (Main Menu > Mod Configuration > ColinsPatchKit).

For the full list of patches (with examples), see [the GitHub README](https://github.com/colinking/sts2-patch-kit#colins-patch-kit).

### Map

![Map tooltip](/docs/images/map-tooltip.png)

- **Current floor tooltip** — Hover the current map floor to see its tooltip, not just previously visited floors.
- **Upcoming floor tooltips** — Hover an upcoming floor for wiki-level odds and expected rewards.
- **Potion chances** — Show the chance of receiving a potion on combat map tooltips.

### Combat

![Retain slots](/docs/images/retain-slots.png)

- **Well Laid Plans retain slots** — Show one dotted card slot per card you can retain.
- **Curses & statuses first when exhausting/transforming** — Sort curses, statuses, and quest cards first when picking a card to exhaust or transform.
- **More active relic pulses** — Pulse more relic icons while their limited effect is still available.
- **Active buff/debuff pulses** — Pulse buff/debuff icons that still have a limited-time effect available this turn.

### Menus

![Random character bans](/docs/images/random-ban.png)

- **Random character bans** — Right-click to ban characters from a random pick.
- **Shop affordability preview** — Hovering a shop item reds out the prices you can't also afford.
- **Hold to confirm leaving a rest site with Tent** — Require a long-press to leave a rest site while you hold Miniature Tent.
- **View Upgrades toggle** — Add the deck view's "View Upgrades" toggle to the card reward screen.
- **Multiplayer cards Compendium toggle** — Default the Compendium's "Multiplayer cards" toggle to match your current run.

### Speed-ups

- **Skip game over animations** — Click to skip the slow game over score reveal.
- **Move shop hand away faster** — Return the merchant's pointing hand to rest faster after you stop hovering.
- **Skip special card reward delay** — Send special card rewards straight to your deck instead of floating them on screen.
